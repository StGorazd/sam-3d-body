How distances are computed

For every vertex of the shaded object, the nearest point on the reference object is found with a BVH: against triangles when the reference is a mesh, against points when it is a cloud. Both objects are transformed by their scale factors first, so distances are in world units. Signed mode takes the sign from the closest triangle's normal (negative = inside).
